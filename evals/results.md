# Ladon evaluation results

Generated by `python -m evals.run_eval`. Each case replays the exact tool calls a fully
compromised assistant would make (one that obeys every injected instruction), first
without Ladon and then through it. This measures the firewall, not the model's caution.
Holds count as stopped: the action waits for a human to verify it through a trusted channel.

## Summary

| Metric | Without Ladon | With Ladon |
|---|---|---|
| Attack cases where the attack succeeded | 21/21 | 3/21 (all 3 are documented known misses) |

| Legitimate actions completed automatically | 24/24 | 23/24 |
| Legitimate actions held for verification (by design) | 0 | 1 |
| Legitimate actions wrongly blocked (false positives) | 0 | 0 |
